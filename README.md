# Meine ersten Arbeiten mit Python

Dieses Repository enthält meine ersten Arbeiten zur Programmiersprache Python. Insgesamt sind 6 verschiedene Dateien vorhanden:

1. **Python Introduction.ipynb**: Einführung in die Programmiersprache Python.
2. **Functions.ipynb**: Verwendung und Bedeutung von Funktionen.
3. **Classes.ipynb**: Klassen und objektorientierte Programmierung.
4. **Python Moduls.ipynb**: Module und deren Verwendung.
5. **Data Structures and Loops.ipynb**: Datenstrukturen und Schleifen.
6. **Try-Except and Functions.py**: Fehlerbehandlung und Funktionen.

## Über

Durch diese Dateien habe ich einen allgemeinen Überblick über die Programmiersprache Python gewonnen. Ich habe die grundlegenden Befehle gelernt und eine Perspektive zu allen Themen entwickelt. Während meiner Erfahrungen habe ich meine Erklärungen manchmal auf Türkisch und manchmal auf Englisch verfasst, um meine Arbeiten besser nachvollziehen zu können.

## Inhalt

Unter jedem Thema finden sich die entsprechenden Arbeiten. So können Sie auf die Details und Anwendungen jedes Themas zugreifen.
